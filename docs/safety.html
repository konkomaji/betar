Safety and limits

This is the most important page on this site. Read it before you rely on Betar for anything real.

No content can be removed once it spreads, not by Betar, not by anyone. There is no server to delete it from. Read "Once it's out, it's out" below before you post anything you might later want to take back.

Delivery is best effort

A message moves only when your phone comes within Bluetooth or Wi-Fi Direct range of another phone running Betar, or when a relay bridge carries it further. There is no guarantee a message arrives, and no guarantee of how long it takes: minutes, hours, or never, depending entirely on which phones happen to be nearby and moving, and whether a relay bridge is ever reached.

Betar cannot help if no other phone is in range and no relay is reached. It carries messages between the phones that are actually present. It cannot conjure a path that does not exist.

No independent security review yet

The cryptography and protocol design follow established, published approaches, but the implementation has not yet had an independent audit. Treat it as you would any early-stage software handling sensitive communication: useful, actively developed, not yet independently verified.

Once it's out, it's out

No server exists to take down a post or message once it has spread across the mesh or the relay network, including by the people who built Betar. This is the direct cost of having no server anyone can be pressured into removing something from. If a post is flagged through Community Notes, each person's own app can locally hide or warn on it, but this never deletes it for anyone else. Think before you post, the same discipline that applies to anything public and permanent.

Location sharing is one tap, one time

The location button inside a chat sends your location once, to that conversation only. There is no live or continuous tracking anywhere in the app. If you share it, it reaches whoever you shared it with and nobody else, the same as any other end-to-end encrypted message.

Report a security issue

If you find a security problem, please report it responsibly through the project's public repository rather than disclosing it publicly first.
